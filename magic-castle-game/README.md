# 🏰 マジックキャッスル 〜まほうのお城のハッピーライフ〜

「ディズニーマジックキャッスル マイ・ハッピー・ライフ2: エンチャンテッドエディション」風の
**お城ぐらしライフシミュレーション 3D ブラウザゲーム**(オリジナルキャラクター版)です。

iPhone / iPad の **縦画面・横画面どちらでも** タッチ操作で遊べます。PC ではキーボード+マウスでも遊べます。

## 🎮 あそびかた

ブラウザで `index.html` を開くだけ(ローカルで遊ぶときは簡易サーバー推奨):

```bash
cd magic-castle-game
python3 -m http.server 8000
# → http://localhost:8000 を Safari / Chrome で開く
```

外部 CDN・ビルド不要。three.js は `lib/` に同梱しているのでオフラインでも動きます。

## ✨ たのしい要素モリモリ

- **美しい 3D の城下町** — シンボルのお城、噴水広場、ベーカリー、ほしみの塔、池、ガーデン。ブルーム(発光)ポストエフェクト+ソフトシャドウ+昼夜サイクルで「最高に綺麗」を追求
- **昼 → 夕焼け → 星空の夜 → 朝** と移り変わる空。夜はお城がライトアップされ、街灯がともり、ほたるが舞う
- **6人の住人(オリジナルキャラ)** — ようせいステラ、はなうさぎルナ、パティシエぐまマロン、おんがくねこフェリクス、つりめいじんポポ、ほしよみふくろうジジ。おさんぽ AI で町を歩き回る
- **おねがい(クエスト)12種** — おつかい・採集・ミニゲーム達成などを住人から受注、達成でコイン&ハピネス&なかよし度アップ
- **🎣 つりミニゲーム** — ウキの「!」であわせてタイミングゲージ。夜限定の魚や、でんせつのクリスタルパーチも
- **🌷 ガーデニング** — タネをうえて、まほうで水やり、時間経過で成長 → しゅうかく
- **🦋 むしとり** — 昼はちょうちょ、夜はほしぼたる。レアほど逃げられやすい
- **💃 ダンスリズムゲーム** — 3レーン落ちものリズムゲーム。コンボでスコアアップ、ランク判定つき
- **🪄 まほうのステッキ** — スパークル魔法で「水やり」「ゴーストばらい」「木をゆすって はちみつ/りんご集め」「住人をよろこばせる」
- **👻 もやもやゴースト** — 町に湧くおばけを魔法ではらってコインゲット
- **✨ ほしのかけら** — 夜に空から降ってくるキラキラを拾い集めよう
- **👗 きせかえ & ショップ** — ドレス8着(にじいろドレスは色が変わる!)、かみかざり6種、ステッキ4種。レベルアップで新商品が解放
- **📖 ずかん** — さかな・むし・おはなのコレクション図鑑&もちもの
- **👑 ハピネスレベル** — ハピネスをためてレベルアップ!花火&紙ふぶきのお祝い、ボーナスコイン、Lv2 以上は夜に花火ショー
- **📷 写真モード** — UI を消してスクリーンショットを保存
- **🎵 オルゴール風 BGM(昼/夜/ダンスの3曲)+効果音** — WebAudio で自動生成、音声ファイル不要
- **💾 オートセーブ** — localStorage に自動保存、「つづきから」で再開

## 🛠 技術構成

- three.js r170(`lib/` に同梱)+ UnrealBloomPass
- 依存パッケージ・ビルド工程なし(素の ES Modules)
- テクスチャは全て Canvas で動的生成、キャラ・建物は全てプリミティブから構築
- `js/core` レンダラー/入力/音/セーブ、`js/world` 空・町・自然・パーティクル、`js/chars` アバター/プレイヤー/NPC、`js/game` 状態・クエスト・ミニゲーム、`js/ui` HUD・パネル

※ 本ゲームはオリジナルキャラクター・オリジナルアセットのみで構成された「風」ゲームです。
