# 🫗 まいにち流体ラボ — 日常の液体シミュレーター

日常にひそむ「液体の場面」を、**本物の流体力学シミュレーション**でリアルに再現して遊べる
iPhone / iPad 向けブラウザアプリです。たて画面・よこ画面のどちらにも対応しています。

## 技術

- **物理**: Particle-based Viscoelastic Fluid Simulation (Clavet et al. 2005) の
  ダブル密度緩和 SPH。粘性(線形+二次)・多相流(混和/非混和)・比重差・
  剛体(浮体)との双方向連成・可動コライダーを実装。約 2,000〜3,200 粒子をリアルタイム計算。
- **描画**: WebGL2 スクリーンスペース流体レンダリング。
  粒子を密度場へスプラットし、しきい値+勾配法線から疑似3Dシェーディング
  (スペキュラ・リム・背景の屈折)。WebGL2 が無い環境は Canvas2D フォールバック。
- **音**: WebAudio によるフル合成効果音 (注ぐ音・水しぶき・炭酸・チャイム)。音源ファイル不要。
- **入力**: マルチタッチ、DeviceOrientation による傾き重力 (iOS は許可ボタンから)。
- 依存ライブラリなし・ビルド不要の純粋な HTML/CSS/JS (ES Modules)。

## 動かし方

ES Modules を使っているため、ローカルでは簡易サーバーで開いてください。

```bash
cd everyday-fluid-lab
python3 -m http.server 8000
# → http://localhost:8000 を iPhone/iPad または PC ブラウザで開く
```

GitHub Pages などの静的ホスティングにそのまま置いても動きます。
