# 🫧 やわらかラボ 〜ぷにぷに素材あそび〜

4歳の指先のための、さわってあそぶ実験場です。文字が読めなくても、ボタンをおすだけで
遊べます。iPhone / iPad Safari 向けのブラウザアプリで、たて画面・よこ画面のどちらにも
対応しています。

## これはなに

ねんど・スライム・もち・プリン…12種類の「やわらかい素材」を、指でこねたり、のばしたり、
あたためたり冷やしたりして遊ぶだけの場所です。クリアもスコアもゴールもありません。
どの触りかたも失敗にならないので、変化していく手ざわりそのものを楽しんでください。

## あそびかた

- サーバー不要。`index.html` をブラウザで開くだけで動きます。
- ローカルで簡易サーバーを立てたい場合は次のどちらでもOKです。

```bash
cd yawaraka-lab
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

- iPhone / iPad の Safari 推奨。ホーム画面に追加すると、アドレスバーのないフルスクリーンで
  遊べます。
- 画面下の素材トレイでさわる素材を選び、画面の道具トレイで道具を選んでから、素材に指で
  触れてください。

## 6つのどうぐ

| 道具 | できること |
|---|---|
| 🖐️ て | つまむ・のばす・押しつぶす。素材にじかに触れる基本の道具 |
| ⭐ 型抜き | ほし・はーと・お花・まるの4つの形でスタンプのように切り抜く |
| 🔥 あたため | じわっと熱を伝える。とろけたり、ふくらんだり、焼き色がついたりする |
| ❄️ ひやす | キンキンに冷やす。パキッと固まったり、カチッと締まったりする |
| 🎨 いろ | 6色のカラーをちょんとつける道具。こねると素材に混ざっていく |
| ✨ トッピング | ほし・はーと・お花・目玉(2個セット)を素材に飾りつけできる |

このほか、素材をまっさらに戻す ↺ リセットと、効果音のオン/オフを切り替える 🔊 ボタンが
あります。

## あそびのヒント

- チョコは指でこすり続けると、じわじわ溶けてとろとろになるよ。
- パンきじはあたためるとふくらんで、こんがり焼き色がつくよ。
- クッキーきじは焼くとパリッと割れやすくなって、サクサク崩れるよ。
- すなねんどは押すとぎゅっと固まり、引っぱるとほろほろ崩れるよ。
- あわはつついてプチプチ弾かせても、しばらくするとまた増えてくるよ。
- 色をちょんとつけてからこねると、素材にじわ〜っと混ざっていくよ。
- 目玉をつけると、素材が生きてるみたいに見えるよ。
- ホイップは何もない場所を指でなぞると、にゅる〜っと絞り出てくるよ。

## ぎじゅつ

- **物理**: 粒子とボンドによるソフトボディ物理シミュレーション。Verlet積分に加え、
  塑性変形・ボンドの破断・近づいたときの再結合をリアルタイムに計算しています。
- **描画**: 粒子から作る密度場をマーチングスクエア法で輪郭化する「グー描画」で、
  ぷにっとした一体感のある見た目を実現しています。
- **音**: 音声ファイルを一切使わず、WebAudioだけで生成する完全プロシージャル効果音。
- **実装**: ビルド不要のプレーンJavaScript(ESモジュールなし、グローバル名前空間
  `window.YL`)。`index.html` を開くだけで動く純粋な静的サイトです。
