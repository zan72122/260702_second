# いちごショートケーキをつくろう! 🍓

添付のコンセプトアート(ちびキャラのパティシエちゃん・ピンクのギンガムチェックキッチン・うさぎ&ひよこのマスコット)にインスパイアされた、**iPhone 縦画面向けのかわいいお菓子づくりゲーム**です。

ブラウザだけで動く純粋な静的サイトです(ビルド不要・依存ライブラリなし)。

## 遊び方

`index.html` をブラウザで開くだけ。ローカルサーバを使う場合:

```bash
cd strawberry-shortcake-game
python3 -m http.server 8000
# → http://localhost:8000 を iPhone / スマホ表示で開く
```

iPhone の Safari で開くと 9:16 のステージが画面いっぱいに表示されます。PC ではマウスでも遊べます。

## ゲームの流れ(ぜんぶで 6 つのミニゲーム!)

| ステップ | あそびかた |
|---|---|
| ❶ ざいりょうをえらぼう | 正しい材料 6 つをタップ! わさび や おさかな にひっかからないでね |
| ❷ スポンジをまぜよう | たまごをパカッと割って、指でくるくる円を描いてまぜまぜ |
| ❸ オーブンでやこう! | 動くゲージを「きつねいろ」ゾーンでストップ! スポンジがふくらむよ |
| ❹ クリームをあわだてよう♪ | ボタン連打 or ゴシゴシこすって シャバシャバ→とろとろ→ふわふわ! まぜすぎ注意! |
| ❺ いちごをきろう | 動くラインが点線のまんなかに来たら「トントン」! リズムよく 8 個 |
| ❻ デコレーションしよう | いちご・クリーム・チョコプレート・ミント・カラースターを自由にドラッグしてデコ! |

さいごは **できあがり!** — 自分でデコったケーキがそのまま登場し、紙吹雪とファンファーレとともに ★ と ♥ のごほうび、SS/S/A/B ランクがもらえます。

## たのしい要素モリモリ

- **レシピえほん**: ステップをクリアするたびに、オリジナルのコンセプトアート 8 枚が 1 ページずつ解放されるギャラリー
- **かくしレシピ**: クリア数に応じて「いちごカップケーキ」「いちごパンケーキ」が解放され、タイトルで選べるように
- **せいせき**: つくったケーキ数・あつめた ★/♥・レシピごとのベストランクを記録(localStorage 保存)
- **おたのしみ**: うさちゃん & ひよちゃんの なでなでモード ♡
- **効果音 & BGM**: すべて WebAudio でリアルタイム合成(音声ファイルなし)。オルゴール風 BGM とかわいい SFX。設定(⚙)で ON/OFF
- コンボ、ぴったりボーナス、パーティクル(キラキラ・ハート・紙吹雪)、マスコットの応援、バイブレーション対応

## フォルダ構成

```
strawberry-shortcake-game/
├── index.html          エントリポイント(390x844 の論理ステージを自動スケール)
├── css/style.css       かわいいデザインシステム(ギンガム・レース・キャンディボタン)
├── js/
│   ├── main.js         起動・シーンルーター・ステージスケーリング
│   ├── state.js        スコア/セーブデータ(localStorage)
│   ├── audio.js        WebAudio 合成 SFX + オルゴール BGM
│   ├── fx.js           パーティクルエンジン(キラキラ/ハート/紙吹雪)
│   ├── ui.js           共通 UI(雲形タイトル・吹き出し・ナビ・モーダル)
│   ├── art.js          SVG アート工房(ちびシェフちゃん・ケーキ・オーブン…)
│   └── scenes/         8 シーン(title / ingredients / mixing / baking /
│                        whipping / cutting / decorating / result)
└── assets/recipe/      レシピえほん用のオリジナルアート(圧縮済み)
```
