# わくわく!ごっこタウン 🎪

「ごっこランド」風の、こども向けお仕事たいけん 3D ブラウザゲームです。
iPhone / iPad の **たて画面・よこ画面どちらでも** 遊べます(タッチ操作前提)。

## あそびかた

1. `index.html` をブラウザで開く(ローカルでは `python3 -m http.server` などで配信してください。ES Modules を使うため `file://` では動きません)
2. タイトルの「🎈 あそぶ!」をタップ
3. タウンで あそびたいおみせをタップすると、お仕事ミニゲームが始まります

## お仕事ミニゲーム(5種類)

| おみせ | あそび |
| --- | --- |
| 🍰 ケーキやさん | まぜて・やいて・クリームとフルーツでデコレーション。注文どおりに作れるかな? |
| 🍣 おすしやさん | お客さんの注文のネタを選んで、どんどんにぎって出そう! |
| 🚚 たくはいびん | トラックで走って、はたの色のおうちにタイミングよくおとどけ! |
| 🚒 しょうぼうし | 画面をタッチしてホースの水でビルの火を消火。さいごはねこちゃん救出! |
| 🛒 スーパーのレジ | ベルトで流れてくる商品をスキャナーの上で「ピッ!」 |

## たのしい要素

- ⭐ 3段階のスター評価と 🪙 コインのごほうび
- 📖 スタンプちょう:5つのお仕事をぜんぶクリアすると「おしごとマスター」!
- 🎁 ぼうしガチャ:コイン20枚で回して10種類のぼうしを集め、キャラクターにきせかえ
- 🎡 観覧車・気球・小鳥・NPCたちが動きまわる にぎやかなタウン
- 🎉 紙ふぶき・キラキラ・ハートなどのパーティクル演出、WebAudio による効果音とBGM
- 💾 進捗は localStorage に自動セーブ

## 技術メモ

- Three.js r170(`lib/` に同梱、ネットワーク不要のスタンドアロン構成)
- UnrealBloom による発光、ソフトシャドウ、ACES トーンマッピング
- アセットはすべてコードで手続き生成(モデル・テクスチャ・音声ファイルなし)
- `viewport-fit=cover` + safe-area 対応、縦横どちらでもカメラが自動調整

## フォルダ構成

```
gokko-land-game/
├── index.html
├── css/style.css
├── js/
│   ├── main.js          # エントリポイント・シーン管理
│   ├── core/            # renderer / audio / save / utils
│   ├── world/           # タウン・空・パーティクル
│   ├── chars/           # キャラクター(こども・どうぶつ・ぼうし)
│   ├── games/           # 5つのミニゲーム + 共通ベース
│   └── ui/              # DOM UI(HUD・リザルト・ガチャ・パネル)
└── lib/                 # Three.js 本体とアドオン
```
