# プリンセス マジカルガーデン 〜まほうの花の島〜

「プリティ・プリンセス マジカルガーデンアイランド」風の 3D ガーデンづくりゲームです。
iPhone / iPad の **縦画面・横画面どちらでも** ブラウザだけで遊べます。

## あそびかた

`index.html` をブラウザで開くだけ(ローカルサーバー推奨)。

```bash
cd magical-garden-island-game
python3 -m http.server 8000
# → http://localhost:8000 を iPhone/iPad/PC のブラウザで開く
```

### そうさ

| そうさ | できること |
|---|---|
| 画面左側をドラッグ | バーチャルジョイスティックで移動 |
| 地面をタップ | その場所へ歩く |
| 画面右側をドラッグ | カメラ回転 |
| 2本指ピンチ | ズーム |
| 花だんをタップ | たねまき / 水やり / 収穫 |
| ちょうちょをタップ | つかまえて図鑑に登録 |
| ようせいをタップ | クエストの確認 |

## ゲームの要素

- 🌷 **ガーデニング** — 10種類の花(チューリップ〜伝説のクリスタルフラワー)。たねをまき、魔法のじょうろで水やりして育てる。ムーンフラワーは夜にだけ咲く!
- ✨ **キラキラとはなびら** — 収穫で通貨をあつめてショップでお買い物
- 👑 **ガーデンレベル** — 花を咲かせるとレベルアップ。虹の演出とともに新しい花・かざり・ドレスが解放
- 🌈 **ひみつのにわ** — レベル3で虹の橋のむこうの浮島が解放
- 🪄 **もようがえ** — ベンチ・ランタン・バラのアーチ・ふんすい・ユニコーン像・ガゼボなど9種のかざりを自由に配置
- 👗 **きせかえ** — ドレス8色(にじいろドレスも!)、髪色5種、ティアラ4種
- 🦋 **ちょうちょ図鑑** — レア度つき7種。夜はホタルも
- 🧚 **ようせいルミ** — 17個のクエストチェーンでゲームを案内
- 🌅 **昼夜サイクル** — 空・海・光がリアルタイムに変化。夜はランタンと星空
- 📷 **写真モード** — UIを消してスクリーンショットを保存
- 🎵 **プロシージャルBGM** — WebAudio によるオルゴール風の音楽と効果音(音源ファイル不要)
- 💾 **オートセーブ** — localStorage に自動保存。るすの間も花が育つ

## 技術

- [Three.js](https://threejs.org/) r170(`lib/` に同梱、ビルド不要)
- UnrealBloomPass による発光表現、ACES トーンマッピング
- カスタムシェーダー: グラデーションスカイ(星空つき)・波アニメーションの海
- すべてのモデル・テクスチャ・音はプロシージャル生成(外部アセットなし)
- セーフエリア(ノッチ)対応、`orientationchange` 対応
