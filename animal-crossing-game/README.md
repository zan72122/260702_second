# どうぶつの島 〜まったりアイランド〜 🏝️

Nintendo「あつまれ どうぶつの森」風の 3D スローライフゲームです。
ブラウザだけで動作し、**iPhone / iPad の縦画面・横画面**のどちらでも遊べます。

## 遊びかた

1. `index.html` をブラウザで開く（ローカルサーバー推奨: `python3 -m http.server` など）
2. なまえと服の色を決めて「島へ しゅっぱつ！」
3. 左下のジョイスティックで移動、右下のボタンで状況に応じたアクション
   - PC の場合は WASD / 矢印キー + Space でも操作できます

※ ES Modules を使用しているため、`file://` 直開きではなく HTTP サーバー経由で開いてください。

## 特徴

### 🌍 まるい地平線の 3D アイランド
- あつ森名物「地面が奥へ丸く落ちていく」曲面ワールドをカスタムシェーダーで再現
- 段丘（崖の上のエリア）・坂道・川・**滝**・砂浜・海のある手作りの島
- あつ森風の三角パターン草地テクスチャを実行時に生成
- 波としぶきがきらめく海シェーダー、流れる川、ゆれる旗、ドリフトする雲

### 🕐 リアルタイム連動の昼夜と天気
- **実際の時刻**と連動して朝焼け・昼・夕焼け・星空へと変化
- 太陽と月が空をめぐり、夜は星とホタルが出現
- 日替わりの天気（雨の日は雨粒エフェクト）
- 時間帯で変わる BGM（朝・昼・夕・夜の 4 曲、WebAudio でリアルタイム生成）

### 🎣 あそび
- **つり**: 川と海で 24 種。魚影の大きさ・時間帯で釣れる魚が変化、食いつきタイミングでヒット！
- **むしとり**: 20 種。チョウは花のまわりを舞い、カブトムシは夜の木に、ホタルは夜の川辺に
- **かせきほり**: 毎日 6 か所に出る★マークをスコップで発掘（8 種のかせき）
- **木ゆすり**: フルーツ 5 種やベル袋が落ちてくる。たまにハチも…！
- **ベルの岩**: 毎日どれか 1 つの岩がベルを吹き出す
- **風船プレゼント**: 空をただよう風船をタップで撃ち落とそう
- **お花**: つんだり、じょうろで水をやると増えたり。タネから育てることも

### 🐾 どうぶつの住民 5 人
- ネコのミケ・イヌのハチ・カエルのケロッタ・クマのモフゾウ・トリのピーコ
- 性格別のセリフ + どうぶつ語ふうボイス（WebAudio 合成）
- なかよし度（ハート）システム。フルーツをプレゼントすると仲良しに、親密になるとお返しも

### 🏪 くらし
- **まめだぬきストア**: 道具・服・花のタネの購入と、なんでも買い取り
- **いきものずかん**: さかな・むし・かせきのコレクションと達成率
- **けいじばん**: 12 種の実績（ごほうびベルつき）と今日の記録
- **しまのちず**: 現在地と住民の居場所がわかるマップ
- **マイホーム**でセーブ + 12 秒ごとのオートセーブ（localStorage）
- 毎日のログインボーナス、日替わりの掘りスポット・ベル岩・天気

## モバイル対応

- セーフエリア（ノッチ・ホームバー）対応の HUD レイアウト
- 縦画面 / 横画面それぞれに最適化された UI
- マルチタッチ（移動しながらアクション可能）、バイブレーション対応（Android）
- `devicePixelRatio` 上限などモバイル GPU 向けの負荷調整

## 技術メモ

- Three.js r170（`lib/` に同梱・オフライン動作可）、ビルド不要のピュア ES Modules
- 地形は数式ベース（高さ・歩行判定・水判定を共有）+ 1024px の焼き込みテクスチャ
- キャラクターはプリミティブ組み立て + 手続きアニメーション
- BGM / 効果音 / ボイスはすべて WebAudio によるリアルタイム合成（音声ファイルなし）
