# 🦖 ヨッシーアイランドストーリー 〜フルーツだいすき!〜

ヨッシーストーリー風の **3D 横スクロールアクションゲーム** です。
Three.js による絵本のようなフル 3D グラフィック(ブルーム発光・ソフトシャドウ・トゥーンシェーディング)で、
フルーツを 30 こ集めてステージクリアを目指します。

すべてのアセット(モデル・テクスチャ・BGM・効果音)はコードから手続き生成しており、
**外部ファイル・ネット接続なしで完全に動作** します。

## 🎮 あそびかた

ローカルサーバーで配信して `index.html` を開くだけです(ES Modules を使うため `file://` 直開きは不可)。

```bash
cd yoshi-story-game
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

### ルール

- ステージのフルーツを **30 こ** 集めるとクリア!(全 3 ステージ)
- **おなじ種類のフルーツを連続で取るとコンボボーナス**(×3 で紙吹雪!)
- 💖 **ハートフルーツ** を取ると 8 秒間の **スーパーハッピーモード**(虹色むてき!)
- ライフは **花びら 8 まい**。敵に当たったり落ちたりすると散ってしまう
- 🌸 スマイルフラワーの **チェックポイント** で復活地点セット & 花びら回復
- 木箱はヒップドロップやタマゴでこわすとフルーツが飛び出す
- 敵を倒してもフルーツを落とすよ

### そうさ (キーボード / ゲームパッド / タッチ対応)

| そうさ | キー |
|---|---|
| はしる | ← → (または A / D) |
| ジャンプ | スペース / Z(空中で長押し = **ふんばりジャンプ**) |
| ヒップドロップ | 空中で ↓ (または S) |
| 舌でパクッ(→タマゴ生成、最大 6 こ) | X / K |
| タマゴなげ(長押しでねらい、はなすと発射) | C / L |
| ポーズ | Esc / P |

### ステージ

1. **うきうき草原** — のどかな昼の草原
2. **ゆうやけビーチ** — ヤシの木と波のゆれる夕暮れの海
3. **きらきらスターナイト** — 星ふる夜空と光る星の木

## 🛠 技術メモ

- **Three.js r160**(`lib/` に同梱、ビルド不要の静的サイト)
- UnrealBloomPass + ACESFilmic トーンマッピング + PCF ソフトシャドウ
- 地形・キャラクター・フルーツはすべてプリミティブ合成 + Canvas テクスチャの手続き生成
- BGM / 効果音は WebAudio でリアルタイム合成(ステージごとに曲が変化、むてき中はテンポアップ)
- `?debug` を URL に付けるとデバッグキーが有効(N: フルーツ+5 / G: ゴール付近へ / H: 花びら1に)

## 📁 構成

```
yoshi-story-game/
├── index.html        # エントリポイント (HUD / 画面 / importmap)
├── lib/              # Three.js 本体 + postprocessing アドオン
└── src/
    ├── main.js       # ゲーム統括 (状態遷移・当たり判定・カメラ)
    ├── world.js      # ステージ生成 (地形・空・雲・丘・木・ゴール)
    ├── player.js     # ヨッシー風プレイヤー (モデル・物理・アクション)
    ├── enemies.js    # 敵 (ヘイホー風・フライヤー・パックン風)
    ├── collectibles.js # フルーツ・コイン・ハート・木箱・ばね床・チェックポイント
    ├── eggs.js       # タマゴ (トレイル・照準・投擲)
    ├── effects.js    # パーティクル・画面シェイク
    ├── audio.js      # BGM / SFX の WebAudio 合成
    ├── ui.js         # HUD・オーバーレイ画面
    ├── input.js      # キーボード / ゲームパッド / タッチ入力
    └── utils.js      # 数学ヘルパー・Canvas テクスチャ生成
```
