# プリンセス マジカルコーディネート 〜きらめきのお城〜

「プリティ・プリンセス マジカルコーディネート」風の、ブラウザで遊べる 3D インテリアコーディネートゲームです。
プリンセス不在で荒廃してしまったお城に迷いこんだ主人公が、**20 のお部屋をぜんぶコーディネートしてお城を復興**させ、元の世界へ帰る扉を開きます。

Three.js を同梱しているため、**ビルド不要・オフラインで動作**します。

## あそびかた

```bash
cd pretty-princess-game
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

(VSCode の Live Server など、任意の静的サーバーでもOK。`file://` 直接開きは ES Modules の制約で不可)

## ゲームの流れ

1. **タイトル → オープニング**: ふしぎな光に包まれて、荒廃したお城へ…
2. **お城のちず**: 20 のお部屋から行き先を選択(復興するごとに次のお部屋が解放)
3. **もようがえ**: カタログから家具・かべがみ・ゆかを選んで配置。「コーデ度」が目標に届くとお部屋が復興!
4. **復興セレモニー**: 灰色のお部屋が色づき、ごほうびのコインとジュエルをゲット。住民(うさぎ・ことり・ねこ・ようせい)も遊びにきます
5. **20 部屋ぜんぶ復興**でグランドフィナーレ!

## 操作

| 操作 | 内容 |
|---|---|
| 左ドラッグ | カメラ回転 |
| ホイール | ズーム |
| ゆかをクリック | プリンセスのおさんぽ |
| (もようがえ中)クリック | アイテムを置く |
| (もようがえ中)R キー | アイテムを回転 |
| (もようがえ中)右クリック / Esc | 選択キャンセル |
| 置いたアイテムをクリック | うごかす・まわす・しまう |

- ✨ **綺麗な 3D**: ソフトシャドウ、ACES トーンマッピング、ブルーム発光、キラキラパーティクル、荒廃⇔復興のトランジション演出

## 技術構成

- **Three.js r170**(`lib/` に同梱、CDN 不要)+ UnrealBloom ポストプロセス
- 家具・キャラクター・テクスチャはすべて**プロシージャル生成**(外部アセットなし)
  - 家具: Lathe / Extrude / プリミティブ合成(ねこあし、フリル、リボン、王冠など共通パーツ)
  - 柄テクスチャ: Canvas 2D で描画(ローズ・ハート・ストライプ・レースなど)
  - BGM/SE: WebAudio のオシレーター合成
- 保存: localStorage(キー `ppmc-kirameki-save-v1`)
