# 🖐💧 てのひら水路ラボ

カメラにうつした **自分の手が、そのまま水路・ダム・うつわになる** 実験あそび。
4歳児向け。勝ち負けもクリアもなし — さわる・ためる・こぼす・ながすのが全部。

## これはなに

上から水やいろいろなものが降ってくる世界に、カメラごしに自分の手が入りこみます。

| てのうごき | おこること |
|---|---|
| 🖐 ゆびを ひらく | ゆびの あいだから 水が すじに なって おちる |
| ✋ ゆびを とじる | 水を せきとめる ダムに なる (ゆびの間に「水かき」が現れるのが見える) |
| 🤲 りょうてで おわん | 水が たまる → ためつづけると 🐟 さかなが あそびに くる |
| 👋 てを うごかす | 水を おせる・はねとばせる |
| ✋ ななめに かたむける | 水の すべりだい (水路) に なる |

**ジェスチャーコマンドは一切ありません。** 「グーだから魔法」のような約束ごとはなく、
手の形・位置・動きがそのまま物理として働きます。画面に光る手の輪郭 = 当たり判定そのもの。

## あそべるもの

- 💧 みず / 🌈 にじいろの水 (まざって色がかわる) / 🍃 はっぱ (手に積もる・水に浮く) / ⭐ ほし (はずむ) / 🫧 あわ (下からのぼる)
- 🦆 あひるボタン: アヒルが降ってきて浮かぶ。手ですくえる・おせる
- ☸️ 水車: 水を当てると回る (流れが強いほど速い)
- 🥛 コップ×2: 水をためると音程が上がり、満タンで 🎉 おいわい → ごくごく → また空に
- 🐟 さかな: 水たまりを1.5秒つづけると出現
- ✨ 水が手にふれるたびに、キラキラ + ペンタトニックの音
- 🖐 15秒さわらないと「おばけの手」が実演してくれる

## あそびかた (起動方法)

カメラを使うため **HTTPS または localhost** で開く必要があります。

```bash
cd tenohira-suiro-lab
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

iPhone/iPad で遊ぶには、HTTPSで配信するか、Mac の Safari から
「ローカルネットワーク上のHTTPS」等で開いてください。縦画面・横画面どちらでも遊べます。

- はじめに「▶ はじめる」をタップ → カメラの許可を求められます
- **カメラが使えなくても遊べます**: 自動で「ゆびモード」になり、
  画面にふれた指がそのまま水をせき止めるカプセルになります (📷 ボタンでいつでも再挑戦)
- モデル読み込み中 (約8MB) も、ゆびモードですぐ遊びはじめられます

### URLパラメータ (開発用)

- `?debug` — FPS/粒子数などのHUD + `window.__app` フック
- `?fakehands` — 合成ランドマークを流し込むテストモード (`&script` で台本再生)
- `?autostart` — ブート画面をスキップ

## 技術

- **手の認識**: MediaPipe Tasks Vision HandLandmarker (21点×2手)。
  wasm もモデルもすべてローカル同梱 — CDN・外部通信なしで動く
- **物理**: 粒子ベース流体 (Clavet 2005 ダブル密度緩和 SPH)。
  手はランドマークから作る約20本のカプセル (指の骨1本ずつ + 手のひら + 指の間の水かき)
- **水かきモデル**: 指の間の膜は「隣の指との距離」に比例して現れたり消えたりする。
  開いた指の間は排水路になり、水は手の奥へ抜け落ちる (2.5D近似) —
  葉っぱやアヒルは落ちずに乗るので、対比が楽しい
- **描画**: WebGL2 スクリーンスペース流体 (カメラ映像を屈折 → 水ごしに自分の手が見える)。
  WebGL2 が無い環境は Canvas2D にフォールバック
- **音**: すべて WebAudio でリアルタイム合成 (音声ファイルなし)
- **ビルドなし・依存なし**: そのまま静的配信するだけ
