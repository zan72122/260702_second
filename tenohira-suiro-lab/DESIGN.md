# てのひら水路ラボ — 設計メモ

## 設計原則

**「手の形そのものが物理」** — ジェスチャー認識コマンド (グー=魔法、チョキ=爆発) は作らない。
4歳児は約束ごとを覚えられないし、覚えさせたら「実験あそび」ではなくなる。
かわりに、手のランドマークの幾何学がそのまま衝突形状になる。
分類器・しきい値のオンオフはどこにもなく、すべて距離に比例した連続量。

**「見えている輪郭 = 当たり判定」** — 手のグロー描画は、物理シミュレーションが使う
カプセル配列と同一のデータから描く。ズレは構造的に起こらない。
子どもが「じぶんの手が世界に入っている」と感じるための最重要ポイント。

**「失敗がない」** — スコア・タイマー・クリア条件・プログレスバーなし (yawaraka-lab と同方針)。
コップの満タンは「ごほうび→リセット」で無限にくり返せる。

## 手のモデル (js/hand/colliders.js)

MediaPipe の21ランドマークから 1手あたり約23本のカプセルを作る:

- **指の骨 15本** — 関節間を結ぶ細いカプセル (半径 = 手のスケール × 0.085)。
  解剖学的比率 (≈0.10) より少し細いのは、開いた指のすき間を
  粒子の相互作用半径より確実に広くするため。
- **手のひら 5本** — 手首から各つけ根へのスポーク (太い)。両手のおわんの器になる。
- **水かき 3本** — 指の間の膜。隣の指 (第2関節同士) の距離が近いほど太く、
  離れると消える。**閉じると膜が現れるのが画面で見える** = 因果の可視化。

### 排水路 (2.5D近似の核心)

2D投影の世界では、開いた指の間のV字すき間は「ポケット」になってしまい、
水がたまるだけで抜けない (実装して実測した)。現実の3D世界では、開いた指の間は
**穴** で、水は手の奥へ抜け落ちる。

そこで、水かきが消えたすき間には「排水路」ゾーンを置く:
ゾーン内の水粒子はその手のカプセルとの衝突をスキップし、重力のまま落下する。
ゾーンは (a) 指先間→つけ根間、(b) つけ根間→真下 (手のひらの裏を抜ける) の2本。
太さは指の開き具合に比例。

- 開いた手に降る雨 → 指の間からすじになって抜け落ちる ✓
- 指を閉じる → 膜がつながり完全なダム ✓
- 葉っぱ・星・アヒル (水以外) は排水路の影響を受けない → 開いた指に乗る。
  「水は抜けるのに葉っぱは乗る」という本物らしい対比が生まれる

### 見失い猶予

トラッキングが一瞬切れても 0.3 秒はカプセルを保持 (速度ゼロで凍結)。
両手のおわんの水が、まばたきのようなドロップアウトで一気にこぼれるのを防ぐ。

## パイプライン

```
カメラ 640×480 (セルフィーミラー)
 → HandLandmarker (VIDEO mode, 2〜3フレームに1回)
 → One-Euro フィルター (静止時なめらか / 高速時低遅延)
 → ミラー + cover-fit 変換 (映像の描画と同一変換 → ピクセル一致)
 → 毎フレーム指数補間 (30Hz検出 → 60fps描画のブリッジ)
 → カプセル群 + 速度 (速度が水を押す)
```

## 物理 (js/engine/sim.js)

everyday-fluid-lab の FluidSim (Clavet 2005 ダブル密度緩和) を拡張:

- カプセル衝突を空間グリッドで枝刈り (手×2 + ガジェットで約60本になるため)
- `pooledClusters()`: 近傍数の多い粒子 (=水中) をBFSでまとめ、
  水たまりの位置とサイズを返す。魚の出現トリガー。
  静止時間ではなく近傍数を使うのは、注がれ続けるおわんの水は常に揺れているから。
- 相: 0=水, 1=にじ色水 (同グループで色が混ざる), 2=あわ (負の重力)
- アヒルは既存の `addSolid` (浮力・起き上がりトルク・squeak フック) そのまま

## 品質の適応 (js/main.js)

frameMs のEMAで3ティア: 粒子上限 1800/1300/900、検出間隔 2/2/3フレーム、
背景アップロード 毎/2フレーム、屈折 on/on/off。縮小はリサイクル経由で目に見えない。

## テスト

`?fakehands` で合成ランドマークを本物のパイプライン (フィルター→変換→カプセル→物理) に
流し込める。Playwright での検証項目:

1. モデル+wasm ロード、カメラ不可時のゆびモードフォールバック
2. ブロブ落下実験: 開いた手は通す (54/196粒)、閉じた手は止める (2粒)、上に乗る
3. 両手おわんが100粒以上保持、手を消すと全部こぼれる
4. スイープで前方の水に +100/s 級の速度が乗る
5. タッチカプセルの生成/物理参加/解放
6. 縦・横画面のワールド構築とアトラクト台本
