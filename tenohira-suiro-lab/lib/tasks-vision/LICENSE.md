# @mediapipe/tasks-vision — ライセンス表記

このディレクトリの内容 (`vision_bundle.mjs`, `wasm/*`) は npm パッケージ
[`@mediapipe/tasks-vision@0.10.14`](https://www.npmjs.com/package/@mediapipe/tasks-vision)
