# 🔆 まいにち光ラボ — 日常の光シミュレーター

日常にひそむ「光のふしぎ」を、**本物の光学計算**でさわって遊べる
iPhone / iPad 向けブラウザアプリです。たて画面・よこ画面のどちらにも対応しています。

## 遊べる日常場面 (24シーン)

| 2 | 🔦 プリズムで分光 | 波長ごとのスネルの法則+フレネル反射 (スペクトルレイトレーシング) |
| 3 | 🥤 コップのストロー | 水面屈折による見かけの位置 (屈折点を数値求解して「折れた」ストローを描画) |
| 4 | 🔍 虫めがねで集光 | 球レンズの焦点・光束密度→加熱 (レイの集中度を実測) |
| 5 | 🪞 鏡で光リレー | 正反射 (入射角=反射角)・多重反射の光学パズル |
| 6 | 💿 CDの虹色 | 回折格子 mλ=d·sinθ (トラック間隔1.6µm、±2次まで) |
| 7 | 🫧 シャボン玉の虹色 | 薄膜干渉 R(λ, 厚み)。重力排水で膜がうすくなり ニュートンの色列→黒膜→破裂 |
| 8 | 🌅 夕焼けメーカー | レイリー散乱 (λ⁻⁴)+ミー散乱をシェーダで計算。太陽高度と光路長 |
| 9 | 🌌 オーロラ観察 | 実在の輝線 (O 557.7nm 緑 / O 630nm 赤 / N₂⁺ 427.8nm 紫) を高度別に発光 |
| 10 | 🌙 月のハロ | 六角氷晶の最小偏角22°リング (内縁が赤い)・幻月・上端接弧 |
| 11 | 🛣️ 逃げ水 | 屈折率勾配のレイマーチ (光線方程式)。視線ごとに「何が見えるか」を計算する本物の蜃気楼 |
| 12 | 💧 水流ライト | 全反射 (臨界角48.6°)。曲がる水流の中の光をジグザグ追跡、もれた光も見える |

| 13 | 🥄 スプーンのさかさま顔 | 凹面鏡の鏡の公式 1/f=2/R。焦点をまたぐと倒立⇔正立が切りかわる |

| 17 | 🏊 水の中から見た空 | スネルの窓 — 視線ごとに屈折/全反射を解いて描画。ふちは分散でにじむ |

| 21 | ⭐ 星のまたたき | シンチレーション — 点光源はゆらぎ直撃、面光源 (惑星) は光路平均でまたたかない |

## 技術

- **物理**:
  - 2D スペクトルレイトレーサ (`js/engine/ray.js`) — 鏡・多角形/円の屈折体・回折格子・スクリーンを
    波長ごとの屈折率 (コーシーの式) とフレネル反射率で追跡
  - 波長→色変換 (`js/engine/spectrum.js`) — CIE 等色関数のガウス近似 → sRGB。
    薄膜干渉・レイリー散乱係数もここで計算
  - 屈折率勾配レイマーチ (`js/engine/march.js`) — 光線方程式 d(nT)/ds=∇n を積分 (蜃気楼)
  - Node ハーネスで事前検証済み: 虹角 42°/51°、プリズム最小偏差=理論値一致、
    臨界角 48.6°、回折角 mλ=d·sinθ 一致、等エネルギー白のバランス
- **描画**: レイは Canvas2D の加算合成 (グロー2パス)。空 (夕焼け・オーロラ・ハロ) は
  WebGL2 フラグメントシェーダで物理項をそのまま計算
- **音**: WebAudio によるフル合成効果音。音源ファイル不要
- 依存ライブラリなし・ビルド不要の純粋な HTML/CSS/JS (ES Modules)

## 動かし方

ES Modules を使っているため、ローカルでは簡易サーバーで開いてください。

```bash
cd everyday-optics-lab
python3 -m http.server 8000
# → http://localhost:8000 を iPhone/iPad または PC ブラウザで開く
```

GitHub Pages などの静的ホスティングにそのまま置いても動きます。
