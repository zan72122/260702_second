# ⏳ まいにち粒つぶラボ — 日常の粒状物シミュレーター

砂・米・雪・ビーズ・豆…日常にひそむ「粒つぶ」の場面を、**本物の粒状体力学シミュレーション**で
リアルに再現して遊べる iPhone / iPad 向けブラウザアプリです。たて画面・よこ画面のどちらにも対応。

## 遊べる日常場面 (12シーン)

| # | シーン | 粒状物の物理 |
|---|--------|-------------|
| 1 | 🏖️ 砂場でお山づくり | 摩擦から創発する安息角・バケツ型ぬき |
| 2 | ⏳ 砂時計をひっくり返す | 細粒のくびれ流下・アーチング |
| 3 | 🍚 お米を計量しよう | 楕円粒の回転・かき出しならし |

| 7 | 🎨 カラーサンドアート | 色砂の層が保存される静力学・棒で模様 |

## 技術

- **物理**: 2D DEM (離散要素法) を Position-Based Dynamics で実装。
  粒子ペアの非貫入射影 + クーロン摩擦 (静止/動) により**安息角が創発**して砂山が積める。
  付着 (雪)・反発 (ガムボール)・転がり抵抗・接触スリップからの回転近似・終端速度・
  スリープ機構 (静止した山は計算スキップ)・剛体円との双方向連成・可動コライダー。
  2,000〜3,200 粒をリアルタイム計算。
- **描画**: WebGL2 インスタンス描画で全粒を 1 draw call。スプライトは起動時に Canvas2D で
  生成してアトラス化 (砂・米・雪・ガムボール・大豆・ポップコーン・リング等 12 種)。
  WebGL2 なしは Canvas2D フォールバック。
- **音**: WebAudio 合成 (粒のパラパラ音は衝突エネルギー連動、ポン!・ザクッ・クルック―・ガチャ)。
- **入力**: マルチタッチ、DeviceOrientation の傾き重力 (砂時計や砂山あそびに)。
- 依存ライブラリなし・ビルド不要の純 HTML/CSS/JS (ES Modules)。

## 動かし方

```bash
cd everyday-granular-lab
python3 -m http.server 8000
# → http://localhost:8000 を iPhone/iPad または PC ブラウザで開く
```

GitHub Pages などの静的ホスティングにそのまま置いても動きます。
